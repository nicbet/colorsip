Colorsip picker test swatches

Open this page in Safari, which color-manages CSS colors, and pick each swatch's center. Compare what the loupe label shows with the expected value under the swatch.

  • sRGB swatches: set the format to CSS Hex. Expect exactly the same hex, including #0000ff and #ffff00.
  • Display P3 swatches: set the format to CSS Display P3. On a P3 display expect the same values within ±0.004 per channel. Swatches marked outside sRGB also list the gamut-mapped CSS Hex. On an sRGB display, out-of-sRGB swatches can't be shown as written.
  • The friendly name is the nearest entry of the bundled color name list.
  • Pixel patterns: each stripe and checker square is one physical pixel. The loupe grid should show them as alternating cells, and each arrow key press should step exactly one cell.

Expected values come from ColorsipCore's own formatters.
